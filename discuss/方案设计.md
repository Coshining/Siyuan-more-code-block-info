# 方案设计：思源「代码块更多信息」插件

## 一、背景与目标

思源笔记原生代码块的标题栏只有左侧语言名和右侧复制/更多两个图标。本插件的目标是把代码块标题栏扩展为更丰富的工具条：

- 左侧：整块收起按钮 + 代码块名称输入框（默认占位「请输入代码块名称」，最多 20 字符）
- 右侧：语言（复用原生，可点击修改）、代码高亮主题、复制（原生）、更多（原生）

并新增两个折叠能力：

- 整块收起：只显示标题栏，持久化到块属性
- 块内折叠：像 VS Code 一样按括号/缩进收起代码区域（采用「失焦折叠、聚焦编辑」的安全模型）

## 二、技术选型

- 构建：Vite + 原生 TypeScript + SCSS
- 类型：`siyuan` npm 包（仅类型 + 运行时桥接）
- 无 UI 框架：本插件主要对既有 DOM 做注入与重排，原生 TS 更轻量

## 三、核心机制

### 1. DOM 结构（已调研确认）

思源代码块由 Lute 生成，结构如下（简化）：

- `.code-block`（`data-type="NodeCodeBlock"`，根元素，携带块 IAL 属性）
  - `.protyle-action`（标题栏）
    - `.protyle-action__language`（语言，点击弹出语言菜单）
    - `.fn__flex-1`（占位）
    - `.protyle-action__copy`（复制）
    - `.protyle-action__menu`（更多）
  - `.hljs`（高亮正文，高亮完成后带 `data-render="true"`；其最后一个子元素是可编辑代码内容）
  - `.protyle-attr`（块属性徽标）

### 2. 注入与重排

通过 `loaded-protyle-static` 事件拿到每个 `IProtyle`，在其 `wysiwyg.element` 上挂 `MutationObserver`，对每个未标记的 `.code-block` 注入自定义头部：

- 左侧：`▼` 整块收起按钮 + 名称输入框
- 右侧：把原生语言 span 移动到右侧、插入主题下拉，复制/更多保持在末尾

由于只是移动/复用原生元素，语言的点击改语言、复制的拷贝、更多的菜单行为全部保持原生。

注入元素对 `pointerdown/mousedown` 阻止冒泡，避免触发思源的块选择与拖拽。

### 3. 数据持久化

三个自定义块属性（写入块 IAL，随文档同步）：

- `custom-code-block-name`：代码块名称
- `custom-code-block-theme`：每块独立高亮主题
- `custom-code-block-fold`：整块收起状态（`"true"`/`"false"`）

写入接口：`/api/attr/setBlockAttrs`；删除：`/api/attr/removeBlockAttrs`。

### 4. 高亮主题

- 主题 CSS 来源：`/stage/protyle/js/highlight.js/styles/<名称>.min.css`
- 作用域隔离：用 CSS `@scope (.code-block[data-code-theme="X"])` 包裹，仅对对应块生效
- 生效优先级：块属性 → 全局默认主题（插件设置） → 空（跟随思源原生主题）
- 全局默认主题存于插件 `config.json`，通过设置面板配置

### 5. 整块收起

给 `.code-block` 设置 `data-fold="true"`，CSS 隐藏 `.hljs` 与 `.protyle-attr`，仅保留标题栏；状态写入 `custom-code-block-fold`。

### 6. 块内折叠（失焦折叠 / 聚焦编辑）

思源代码块正文是 `contenteditable`，且会被 highlight.js 动态重写。为了兼顾「实时折叠」与「安全编辑」，采用以下模型：

- 始终按行渲染：代码正文按行拆分为行内 `.code-line` 元素（换行符保留在元素内部，避免 `white-space: pre-wrap` 下多出空行），按缩进 + 括号平衡计算可折叠区间，左侧用行内 `::before` 渲染折叠箭头；折叠时隐藏对应行（`display:none`）并同步隐藏思源行号容器里的对应行号
- 实时同步：编辑过程中监听 `input` / `keyup`，结构签名（行数 + 折叠区间 + 折叠状态）变化时重建 DOM；重建前后按文本偏移保存/恢复光标；输入法组合输入期间不重建
- 聚焦不再还原原始 HTML，折叠视图在编辑时保持可见，折叠箭头点击即时生效
- 折叠箭头点击时通过 `mousedown` 阻止焦点进入，保证点箭头不会触发编辑

## 四、目录结构

```
src/
  index.ts              插件入口
  index.scss            全部样式
  constants.ts          常量
  types.ts              强类型
  context.ts            运行时上下文（插件实例、配置）
  api.ts                块属性读写
  settings.ts           全局默认主题设置面板
  util/logger.ts        控制台日志
  core/
    observer.ts         MutationObserver 管理
    headerInjector.ts   标题栏注入与重排
    nameInput.ts        名称输入
    themeSelector.ts    主题下拉与应用
    themeCss.ts         主题 CSS 抓取与作用域
    collapse.ts         整块收起
  fold/
    regionParser.ts     折叠区间计算
    foldView.ts         折叠视图渲染/还原
```

## 五、已知限制与说明

1. `icon.png`/`preview.png` 为占位图，后续可替换。
2. 插件运行在浏览器/Electron 渲染进程，无法直接写 `logs/` 文件，日志输出到开发者工具控制台。
3. `@scope` 依赖现代 Chromium（Chrome 118+），思源桌面/移动端均满足；不支持的极少数环境回退为选择器前缀重写。
4. 块内折叠视图按行重新高亮，多行结构（如块注释、模板字符串）的跨行高亮可能与实时编辑态略有差异；聚焦后恢复为思源原始渲染，不影响数据。
