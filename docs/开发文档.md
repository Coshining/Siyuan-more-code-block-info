# 开发文档：代码块更多信息插件

## 1. 环境要求

- Node.js >= 20.11（推荐 20+，`import.meta.dirname` 需要 20.11+）
- npm（已封装进 `scripts/` 脚本）
- 思源笔记 3.8.5+

## 2. 目录结构

```
.
├── plugin.json         插件配置
├── package.json
├── tsconfig.json
├── vite.config.ts      Vite 构建配置
├── icon.png            插件图标（160×160）
├── preview.png         预览图（1024×768）
├── i18n/               国际化
│   ├── zh_CN.json
│   └── en_US.json
├── scripts/            启停与构建脚本
│   ├── install.sh / install.ps1
│   ├── build.sh / build.ps1
│   ├── dev.sh / dev.ps1
│   ├── clean.sh / clean.ps1
│   └── clean.mjs
├── src/                源码
├── docs/               正式文档
└── discuss/            讨论文档
```

## 3. 安装依赖

Linux/macOS/WSL：

```bash
scripts/install.sh
```

Windows PowerShell：

```powershell
.\scripts\install.ps1
```

## 4. 构建

```bash
scripts/build.sh        # Linux/macOS/WSL
.\scripts\build.ps1     # Windows PowerShell
```

构建产物：

- `dist/`：插件目录（index.js、index.css、plugin.json、icon.png、preview.png、README、i18n）
- `package.zip`：可发布到集市的压缩包

## 5. 本地调试

### 5.1 热构建

```bash
scripts/dev.sh          # Linux/macOS/WSL
.\scripts\dev.ps1       # Windows PowerShell
```

输出到 `dev/` 目录。

### 5.2 安装到思源

把 `dist/`（或 `dev/`）目录放入思源工作空间 `/data/plugins/` 下，命名为插件名目录（如 `siyuan-more-code-block-info`），然后在思源「设置 → 集市 → 已下载」中启用插件；或直接刷新思源。

开发时建议把 `dev/` 软链接到插件目录，保存代码后刷新页面即可看到效果。

## 6. 调试要点

- 打开思源开发者工具（`Ctrl/Cmd + Shift + I`），查看控制台日志，前缀为 `[more-code-block-info]`。
- 修改代码后重新构建，再刷新思源页面或禁用/启用插件。
- 若标题栏注入不生效，先确认代码块根元素为 `.code-block` 且带 `data-type="NodeCodeBlock"`。

## 7. 发布

1. 修改 `plugin.json` 的 `version`。
2. 运行构建脚本生成 `package.zip`。
3. 在 GitHub 仓库创建对应版本号的 Release，上传 `package.zip`。
4. 首次发布需向 `siyuan-note/bazaar` 提交 PR，把仓库加入 `plugins.json`。

## 8. 代码约定

- 全程强类型，禁止 `any`（个别与第三方类型交互处如确需，需注释说明）。
- 单个 TS 文件不超过 300 行，每层目录文件数不超过 8 个。
- 日志统一走 `src/util/logger.ts`。
