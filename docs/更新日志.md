# 更新日志

本文件记录「代码块更多信息」插件的版本变化。版本号与 `plugin.json`、`package.json` 保持一致。

## 0.1.6（2026-11-03）

修复禁用插件时未还原 DOM 变更的问题。

### 修复

- 禁用插件时移除注入的收起按钮、名称输入框、主题下拉与块状态属性（`data-more-code-info`、`data-fold`、`data-code-theme`）。
- 移除动态注入的高亮主题 `<style>`，并阻止卸载后仍在途的请求继续注入样式。
- 关闭并移除挂到 `body` 上的主题菜单浮层。
- 卸载名称输入框的事件隔离、光标保护全局监听与聚焦轮询定时器。
- 还原代码块语言标签被移除的 `protyle-action--first` class。
- 编辑器销毁时同步还原该编辑器内的代码块 DOM。

## 0.1.5（2026-11-03）

首个公开版本，提交思源社区集市。

### 功能

- **代码块名称**：标题栏内直接输入，最多 20 个字符，失焦保存到块属性 `custom-code-block-name`。
- **语言**：保留思源原生语言标签并移动到标题栏右侧，点击仍可切换语言。
- **高亮主题**：每个代码块可独立选择 highlight.js 主题，设置中可配置全局默认主题，支持「跟随思源」。
- **整块收起**：只保留标题栏，状态保存到块属性 `custom-code-block-fold`。
- **原生按钮**：保留思源的复制与更多按钮，行为不变。
- **国际化**：内置简体中文与英文文案。

### 兼容性

- 思源笔记 3.8.5 及以上。
- 桌面端、移动端、浏览器端。

### 发布相关

- 图标调整为 160×160（≤64 KB），预览图调整为 1024×768（≤512 KB），满足集市体积限制。
- `plugin.json` 的 `backends` / `frontends` / `kernels` 统一为 `["all"]`，避免集市校验失败。

## 更早版本

0.1.5 之前的版本仅在本地迭代，未单独发布。主要探索内容包括：

- 代码块标题栏注入与原生元素重排；
- 代码块内按缩进折叠的交互（已在 0.1.5 中移除，仅保留整块收起）；
- 折叠边界处退格 / 删除键的处理。
